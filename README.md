# Pearl Sandbox

Hey, I built this project to mess around with 3D physics in the browser using Three.js and Cannon.js without big game engines.
It started as a simple bouncing ball test and turned into a glass box where you can spawn hundreds of pearls. You can click any face of the container to shoot pearls inside, drag the slider to change the box size, or toggle gravity to make everything float to the ceiling.
I built it with vanilla HTML, CSS, and JS. The trickiest part was fixing wall clipping when too many pearls spawned, which I solved by using thicker collision boxes for the walls.
No npm or build steps needed, just open index.html in your browser. Check out the screenshots below.
